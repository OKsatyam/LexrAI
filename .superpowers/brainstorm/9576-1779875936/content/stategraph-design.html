Phase 3: ReAct StateGraph Design

How the agentic Improve pipeline flows — nodes, edges, state

StateGraph

START
↓
decide_node — LLM picks next tool or "done"
↙↓↘↓ done / iter≥5
ruff_node bandit_node radon_node explain_node
↘↓↙ ↓
← loop back (iter < 5)
↓
END

AgentState (TypedDict)

repo_id: str
repo_path: str
findings: list[Finding] # accumulated
tools_run: list[str] # ["ruff","bandit"]
messages: list # LLM conversation
iterations: int # hard cap: 5
done: bool
final_findings: list[dict]

Node responsibilities

decide_node — LLM sees findings so far + tools already run → outputs next tool name or "done"
ruff_node — runs ruff subprocess → appends findings, adds summary to messages
bandit_node — runs bandit subprocess → same pattern
radon_node — runs radon subprocess → same pattern
explain_node — LLM receives all findings → outputs explanations → stored in DB

Conditional edge logic

# after decide_node:
if done or iterations >= 5 → explain_node
if next_tool == "ruff" → ruff_node
if next_tool == "bandit" → bandit_node
if next_tool == "radon" → radon_node
# after any tool node:
always → decide_node (loop)

Rate limit protection: 2s delay before each decide_node LLM call. Max 5 iterations = max 6 LLM calls (5 decide + 1 explain). Well within Groq 30 RPM.
